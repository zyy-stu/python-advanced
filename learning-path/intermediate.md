# 中级学习路线

## 适合人群与前置条件

已掌握函数、容器、类和异常的读者。从 [Python 基础教程](https://github.com/zyy-stu/python-basic)或[路线入口](README.md)补齐前置知识。

## 学习目标

能够解释装饰器、迭代器、生成器与描述符，演示异常路径并通过测试。

## 推荐顺序

1. [Python 数据模型](../docs/01-python-data-model/README.md)
2. [函数高级特性](../docs/02-functions-advanced/README.md)
3. [迭代器与生成器](../docs/03-iterators-generators/README.md)
4. [上下文管理器](../docs/04-context-managers/README.md)
5. [面向对象高级机制](../docs/05-object-oriented-advanced/README.md)
6. [类型系统](../docs/10-type-system/README.md)
7. [工程化实践](../docs/13-engineering-practices/README.md)

## 重点难点

区分迭代协议、生成器状态和闭包捕获。学习描述符时记录实例与类属性查找顺序。

## 推荐实战

完成带输入校验、惰性数据流和资源管理的命令行工具。

## 完成标准

能够解释装饰器、迭代器、生成器与描述符，演示异常路径并通过测试。 请让另一位读者在干净环境重复验证。
