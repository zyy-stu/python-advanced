# 上下文管理器

本章研究进入退出协议与异常传播。完成后应能解释相关执行过程，并用上下文管理器回滚失败操作。

[迭代器与生成器](../03-iterators-generators/README.md)

## 课程顺序

1. with 语句，计划文件 `01-with-statement.md`。
2. 上下文管理协议，计划文件 `02-context-manager-protocol.md`。
3. contextlib，计划文件 `03-contextlib.md`。
4. 自定义上下文管理器，计划文件 `04-custom-context-manager.md`。

## 难点与实践

重点是解释进入退出协议与异常传播的边界，记录实际输出以及失败场景。实践任务：用上下文管理器回滚失败操作。完成后提交一次可复现的验证记录。
