# 函数高级特性

本章研究函数对象、绑定与调用。完成后应能解释相关执行过程，并用闭包实现可配置装饰器并保留签名。

## 前置知识

[Python 基础教程](https://github.com/zyy-stu/python-basic)

## 课程顺序

1. 一等函数，计划文件 `01-first-class-functions.md`。
2. 闭包，计划文件 `02-closures.md`。
3. 装饰器，计划文件 `03-decorators.md`。
4. 高级装饰器，计划文件 `04-decorator-advanced.md`。
5. 函数签名，计划文件 `05-function-signatures.md`。
6. 参数传递，计划文件 `06-argument-passing.md`。
7. LRU 缓存，计划文件 `07-lru-cache.md`。

## 难点与实践

重点是解释函数对象、绑定与调用的边界，记录实际输出以及失败场景。实践任务：用闭包实现可配置装饰器并保留签名。完成后提交一次可复现的验证记录。
