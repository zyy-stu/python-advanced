# 元编程

本章研究类创建与自省。完成后应能解释相关执行过程，并在类创建时验证插件契约。

## 前置知识

[面向对象高级机制](../05-object-oriented-advanced/README.md)

## 课程顺序

1. 动态属性，计划文件 `01-dynamic-attributes.md`。
2. 动态类，计划文件 `02-dynamic-class.md`。
3. type 与元类，计划文件 `03-type-and-metaclass.md`。
4. 元类，计划文件 `04-metaclass.md`。
5. 类装饰器，计划文件 `05-class-decorators.md`。
6. 自省，计划文件 `06-introspection.md`。

## 难点与实践

重点是解释类创建与自省的边界，记录实际输出以及失败场景。实践任务：在类创建时验证插件契约。完成后提交一次可复现的验证记录。
