# 性能优化

本章研究从可重复测量到优化复验。完成后应能解释相关执行过程，并对热点函数比较缓存前后的耗时和内存。

## 前置知识

[内存管理](../07-memory-management/README.md)、[并发编程](../08-concurrency/README.md)

## 课程顺序

1. 性能分析，计划文件 `01-performance-analysis.md`。
2. cProfile，计划文件 `02-cprofile.md`。
3. timeit，计划文件 `03-timeit.md`。
4. 内存剖析，计划文件 `04-memory-profiler.md`。
5. 算法优化，计划文件 `05-algorithm-optimization.md`。
6. 缓存，计划文件 `06-caching.md`。

## 难点与实践

重点是解释从可重复测量到优化复验的边界，记录实际输出以及失败场景。实践任务：对热点函数比较缓存前后的耗时和内存。完成后提交一次可复现的验证记录。
