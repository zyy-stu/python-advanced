# 并发编程

本章研究共享状态、进程隔离与调度。完成后应能解释相关执行过程，并用同一任务对比线程池与进程池。

## 前置知识

[Python 数据模型](../01-python-data-model/README.md)

## 课程顺序

1. 多线程，计划文件 `01-threading.md`。
2. 线程池，计划文件 `02-thread-pool.md`。
3. 多进程，计划文件 `03-multiprocessing.md`。
4. 进程池，计划文件 `04-process-pool.md`。
5. 队列与锁，计划文件 `05-queue-and-lock.md`。
6. GIL，计划文件 `06-gil.md`。
7. 并发模型，计划文件 `07-concurrency-model.md`。

## 难点与实践

重点是解释共享状态、进程隔离与调度的边界，记录实际输出以及失败场景。实践任务：用同一任务对比线程池与进程池。完成后提交一次可复现的验证记录。
