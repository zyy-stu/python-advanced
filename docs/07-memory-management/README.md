# 内存管理

本章研究对象生命周期与内存观测。完成后应能解释相关执行过程，并借助弱引用和快照定位对象滞留。

## 前置知识

[Python 数据模型](../01-python-data-model/README.md)

## 课程顺序

1. 引用计数，计划文件 `01-reference-counting.md`。
2. 垃圾回收，计划文件 `02-garbage-collection.md`。
3. 循环引用，计划文件 `03-cyclic-references.md`。
4. 弱引用，计划文件 `04-weak-reference.md`。
5. 内存分析，计划文件 `05-memory-profiling.md`。
6. 内存优化，计划文件 `06-memory-optimization.md`。

## 难点与实践

重点是解释对象生命周期与内存观测的边界，记录实际输出以及失败场景。实践任务：借助弱引用和快照定位对象滞留。完成后提交一次可复现的验证记录。
