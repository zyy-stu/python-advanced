# 推荐学习依赖

下列箭头表示推荐顺序。可以从已经掌握的节点进入，也可以按实践需求并行推进。

- 对象模型 → 特殊方法 → 数据模型协议 → 迭代器与生成器 → 上下文管理器。
- 函数基础 → 闭包 → 装饰器 → 高级装饰器应用。
- 面向对象 → 继承 → MRO → 描述符 → 元类 → 元编程。描述符的属性查找规则本身可独立学习。
- 对象引用 → 引用计数 → 垃圾回收 → 弱引用 → 内存优化。
- 线程与进程 → 并发模型 → GIL → 任务调度。
- 协程 → async/await → 事件循环 → Task → 异步 I/O → 异步项目。
- 类型注解 → Generic → Protocol → 高级类型系统。
- 性能分析 → 性能定位 → 算法优化 → 缓存 → 工程优化。

闭包和对象模型可并行入门。类型注解可与内存、并发同时学习。掌握函数和运行环境后可先测量单个函数，随后再研究并发性能。
