# 高级示例

使用 Python 3.11+，在仓库根目录运行。全部示例仅使用标准库。

- [自定义迭代器](iterators/countdown.py)，运行 `python examples/iterators/countdown.py`。
- [闭包和装饰器](decorators/closure.py)，运行 `python examples/decorators/closure.py`。
- [自定义上下文管理器](context-managers/temporary_value.py)，运行 `python examples/context-managers/temporary_value.py`。
- [描述符](descriptors/positive.py)，运行 `python examples/descriptors/positive.py`。
- [asyncio 并发任务](asyncio/concurrent_tasks.py)，运行 `python examples/asyncio/concurrent_tasks.py`。

后续扩展示例包括数据模型和特殊方法、生成器、元类、内存管理、线程、多进程及性能分析。
